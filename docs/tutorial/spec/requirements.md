## 执行摘要（给改写执行阶段的要点）

1. **读者定位**：通用基础概念（如 CLAUDE.md、Skill、VitePress 这类，按篇而定）不用从零教，概念表快速带过；重心是"这部分怎么设计的、为什么、代码去哪读"。
2. **去重**：原文中与前文重复的内容（如各节重复交代"怎么用、影响什么"）合并压缩，这是用户明确追加的要求。
3. **图表分工**：mermaid 负责流程与关系，表格负责对照；每篇各选最有价值的几处，两者都不滥用。
4. **链接规范**：全部用当篇指定 commit 的固定链接 + 行号锚点（形如 `路径/文件.md#L58-L129`）；原文已有的该格式链接保持。
5. **学习目标**：开篇简短列出，几行即可，不展开。
6. **设计决策/考证类章节**：后置为附录风格。
