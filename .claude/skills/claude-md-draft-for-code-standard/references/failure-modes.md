# 已知失败模式登记表

> 本文件职责：登记 claude-md-draft-for-code-standard skill 运行全程的已知失败模式，给出症状识别判据与预防规则。
> 上游：skill-design.md 的 §2-§7（来源判型、步骤流、验证四态、红线、并发、评审落盘）与 references/scoring.md §1.2（内容保真）。
> 下游：第⓪步与步骤①-⑨执行时逐条自检；skill 打包后作为 references/ 底稿。

## 使用规则

- 第⓪步来源登记完成后，通读本表一次。进入①-⑨各步前，对照本步可能命中的模式逐条自检。
- 每条预防规则均为硬规格：命中「症状」即执行对应「预防规则」，禁止静默忽略。
- 来源编号沿用主文档定义：SRC-1 已有代码目录；SRC-2 会话记录与事故复盘；SRC-3 库依赖清单；SRC-4 技术栈口述；SRC-5 项目约束文档；SRC-6 现成编程规范文档。
